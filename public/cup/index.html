🏆 송도마스터즈 회장기대회

📜 대회 방식

  • 조편성: 평균타수(핸디)순으로 1조부터 배정 — 9·10월 정라 성적이 입력되면 실시간 자동 반영됩니다. 평균타수가 같으면 직전월 타수가 낮은 사람이 앞 순번.
  • 8월(알펜시아)은 이벤트성 라운딩이라 평균타수 계산에서 제외됩니다. (출석횟수에는 포함)
  • 순위: 대회 당일 스트로크 그대로 각 조 1~4등 결정. (동타 시 출석횟수 + 찬조횟수가 많은 사람이 상위)
  • 상품 우선권: 각 조 1등들 → 2등들 → 3등들 → 4등들 순. 같은 등수끼리는 출석횟수 + 찬조횟수가 많은 사람이 먼저. (출석·찬조 모두 월 1회로 집계 — 한 달에 여러 건 찬조해도 1회)
  • 상품: 대회월 찬조상품 + 총무 등록 상품.

🏌️ 조편성 핸디순 실시간

✏️ 관리자 모드: 당일타수 칸 클릭=스코어 입력 · 핸디 칸 클릭=핸디 고정(비우면 자동/미정) · 이름 앞 ✖=참가 제외

🎖️ 상품 선택 우선순위 각 조 등수 → 출석 + 찬조 많은 순
